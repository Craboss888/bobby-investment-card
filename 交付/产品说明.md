# 我的投资卡片：不用开户，Bobby 的每个回答都和你有关

> 一句话：一张「投资版 MBTI」式的投资卡片——把用户的持仓、关注和投资偏好沉淀成看得见、可编辑的个人 profile，让还没在 RockFlow 开户的早期用户也能拿到个性化价值，并因此每天回来。

**目标指标：早期用户（未绑定账户）的 7 日留存。** 次要观察：人均对话轮次、卡片相关追问点击率。

## 为什么是这个问题

我用一个未绑定券商的账号实际体验了 Bobby（2026-10-14），Bobby 承诺的「理解自己的持仓」在这类用户身上基本落空：

1. 首页「持仓分析」的推荐问题，点了直接回「没连 RockFlow 账户」加一张开户卡。
2. 「每日持仓简报」写着「你尚未授权」，内容是所有人都一样的大盘新闻。
3. 在对话里贴过持仓，开新对话再问，Bobby 回「读不到」，要求重贴。
4. 回答质量很高，但读完就结束：结尾只有赞 / 踩 / 分享，没有下一步。

**在用户愿意开户之前，Bobby 对他一无所知、也不记得他。** 持仓分析这类核心功能只能给出千篇一律的回答——谁来问都一样，用户感受不到价值，很快就弃用。这直接压着留存。

现有的开户流程解决不了这个问题：

- **门槛高**：开户流程长，涉及 KYC，是重决策；很多用户的钱在富途、老虎、Robinhood，Bobby 连不上。
- **开了户也是空仓**：就算用户开了户，进来的也是一个空的持仓，Bobby 仍然拿不到他的数据。

所以需要一种不用开户、低门槛就能拿到用户 profile 的方式。

## 它怎么提升留存

1. **首页按你定制**：和你持仓有关的热点排到最前（「和你的 NVDA 直接相关」），每日简报只讲你的股票。第二天早上回来看到的是自己的组合怎么了——这是回来的理由。
2. **回答按你定制**：同一条热点，回答先说「和你有关」的部分、对你意味着什么；回答后给按持仓生成的追问，顺带提高对话轮次。
3. **越用越懂你**：对话里问到卡片外的股票，自动记进关注（明说、可撤销），卡片越用越完整，Bobby 越懂你，形成使用飞轮。
4. **可分享**：投资版 MBTI 式的称号和维度，适合晒出去，带来社交传播（次要，不作为成败判断）。

## 目标用户与场景

- **主要**：已在别家券商炒美股、还没在 RockFlow 开户的轻度投资者。场景：听说 Bobby，打开看看热点，想知道「这和我有什么关系」。
- **次要**：还没买过股票的新手。场景：第一次打开，只会点首页现成的问题。

## 核心交互

1. **建卡（约 30 秒）**：先告诉 Bobby 你有什么（二选一），再答两道行为题。
   - 有持仓：在别家券商截一张持仓页，传给 Bobby → 识别出代码和仓位比例（金额自动打码）→ 用户确认、修改。
   - 没持仓或不想截图：在一屏热门股里点选关注的股票。
   - 两条路之后都接两道行为题：「跌 20% 你会怎么做」「这笔钱打算放多久」。已经答过的不再问。
2. **卡片**：称号加一段特征描述（像星座书写星座特征），风险偏好、集中度、持有周期、杠杆四个维度，一条「盲点」，以及仓位构成。例如「单核信仰者——几只股票其实押的是同一个赌注」。可分享（分享图不含金额）。称号让建卡更好玩，不是功能本身。
3. **自动沉淀**：用户问过的股票、点开的热点，回答下方出现「已加入你的卡片 · 撤销」。卡片对用户完全透明，每一条都能删。
4. **用卡片的地方**
   - 回答后追问：Bobby 分析完，按卡片给 2–3 个针对性追问，如「这对我的 NVDA 意味着什么？」。
   - 每日简报：围绕卡片上的股票写，而不是大盘通用新闻。这是每天回来的理由。
5. **开户是最后一级台阶**：卡片底部「想让持仓每天自动同步？绑定账户」。

## 为什么不是另外几个

| 考虑过的方案 | 为什么没选 |
|---|---|
| 只做回答后的追问建议 | 最好做，但没有用户信息时追问只能泛泛而谈；作为本功能的子功能，有了卡片才有针对性 |
| 只靠对话中用户口述持仓 | 新手不会主动说、说不全，首页现成问题也没有说的机会；保留为卡片的补充来源 |
| 调仓计划跟进（Bobby 给的多步计划变成打卡提醒） | 对留存很强，但等于跟踪「投资建议」的执行，合规风险最高 |
| 新手引导问卷 | App 已有 5 步问卷，问完不沉淀成用户看得见、用得上的东西；其中「投资经验」一题并入建卡 |
| 接入多券商账户聚合（Plaid / SnapTrade 类） | 工程与合规成本高，覆盖不了用户常用的富途、老虎 |

## 明确不做

- 不接真实账户与行情；截图识别在原型里用预置结果模拟。
- 卡片、简报、追问只解释风险暴露，不给买卖数量、价格或目标价。
- 不展示金额、累计收益和盈亏，不做收益排行；分享图不含任何金额与收益。简报里的单日波动只按卡片比例估算，用来解释风险暴露（例如「TQQQ 一格贡献了近一半的波动」），不是账户盈亏。
- 称号不奖励高风险或高频交易：没有「加杠杆解锁成就」，每个称号都带一条盲点。
- 不做社交关注、跟单。
- 原型不做、文档中提出的下一步：热点「看涨 / 看跌」立场投票记入卡片；从对话中提取偏好（如「怕回撤」「偏长线」）写入卡片。
