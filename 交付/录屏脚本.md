# 录屏脚本（≤ 3 分钟）

## 录之前

1. 打开 `demo/index.html`（双击即可）；浏览器全屏，窗口约 1440×900，能看到手机两侧的作品说明和「演示控制」。
2. 点右侧「演示控制 → 从引导开始」，确保从干净状态开始。
3. 用 macOS 自带录屏（⌘⇧5 → 录制所选部分），框住整个浏览器内容区；打开麦克风边录边讲，或者录完配音。
4. 先完整走一遍彩排，再正式录。回答是逐字输出的，每条约 6–8 秒，留足说话时间就不显得慢。

## 备选镜头（时间够或想换着讲）

- **未建卡的对比**：开头先在首页点「持仓分析 → 我的持仓里有没有风险比较大的?」，展示「你还没有授权账户」的死路，再点回答下方的「不用开户：截一张持仓图建投资卡片」进入建卡。约 20 秒，适合放在 0:15 之后，替代引导页。
- **对话里说出持仓**：新对话输入「我有 TSLA 和 NVDA 各一半」，回答下方出现「把 NVDA、TSLA 存进投资卡片」，一键生成卡片。
- **问买卖**：建卡后输入「我该不该卖掉 TQQQ？」，展示「我不替你决定」式的回答，适合讲合规边界。

## 注意

- 状态栏时间是演示设定：第一天 21:30，第二天 8:30。
- 录完检查一遍时长，超过 3 分钟就去掉 1:10–1:20 那段首页停留。
