# 风险说明：投资建议与合规边界

## 本功能怎么处理

| 风险点 | 处理 |
|---|---|
| **卡片被理解为投资建议** | 卡片、简报、追问只描述风险暴露（集中度、杠杆、行业重叠），不给买卖数量、价格或目标价；追问是问题，不是指令。 |
| **称号的游戏化** | 有先例：Robinhood 在 2020 年被马萨诸塞州证券监管部门起诉，指其撒彩带等游戏化设计诱导散户频繁交易，后来撤掉了这类动画。所以称号只「照镜子」不「发勋章」：描述持仓结构，每个配一条盲点；没有夸奖高风险的称号，不做交易次数或杠杆相关的成就。 |
| **分享带来的炫耀与跟风** | 分享图只有称号、盲点和仓位比例，不含金额、收益和盈亏；不做收益排行和跟单。 |
| **截图隐私** | 只识别代码和比例；提示用户金额可以打码；原图识别后不保存；卡片每一条可删，可整张清空。 |
| **自动记录让人不安** | 每次写入卡片都在界面上明示「已加入你的卡片 · 撤销」，不在后台静默记录。 |
| **用户直接问「该不该买 / 卖」** | 已建卡时不替用户决定：把这只股票放回卡片里，说明它的分量、再跌 20% 对组合的影响、用户建卡时说过的偏好，再给三个自问的问题。 |
| **新手看到激进做法** | 引导里选了「新手入门」的用户，热点回答隐藏「激进」短线做法，并注明原因。 |
| **卡片被当成适当性评估** | 卡片里的「经验」「偏好」只用于调整讲解的深浅（如对新手少用术语），不替代开户时的正式 KYC 与风险测评。 |
| **免责提示** | 卡片页和简报底部固定一行：「内容基于你提供的信息，仅供参考，不构成投资建议」。 |

## 体验中观察到的现有边界问题（供团队参考）

我在 2026-10-14 用未绑定账户体验 Bobby 时注意到：

1. 贴出持仓后，Bobby 没有询问年龄、投资期限、目标，就给出具体调仓指令（如某 ETF 从 20% 降至 0%、某股减约 4,500 美元）。
2. 对自称「第一次买美股」的用户，建议「先买 7 股」并给出止损价，讲解中用了 MACD、KDJ、SAR、ADX 等术语。
3. 回答页面内没有看到免责提示。
4. 一条劝用户「别全仓」的回答中间插入了开户卡片。

也有做得好的地方：拒绝预测「明天会涨吗」，劝阻新手全仓，并量化了全仓风险。本功能的卡片可以为这些回答提供「这个用户是新手」的上下文，让讲解更匹配，但具体建议的边界仍需 Bobby 回答侧统一把关。
